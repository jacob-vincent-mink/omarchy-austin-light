# Austin

An Omarchy light theme inspired by Austin's skyline and Lady Bird Lake. Its palette draws on limestone, river blue, and park trees in daylight. The wallpapers are coordinated retro travel-photo edits with warm print colors, muted teal water, and subtle film grain.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-austin-theme.git`. To use an existing local copy, run `omarchy theme set Austin`. Cycle through the four wallpapers with `omarchy theme bg next`.

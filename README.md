# Omarchy Austin Light

A light Omarchy theme inspired by Austin's skyline and Lady Bird Lake. Limestone surfaces, river blue, and park green pair with two daylight wallpapers.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-austin-light.git`, then run `omarchy theme set austin-light`. Cycle the two wallpapers with `omarchy theme bg next`.

For the night and sunset wallpapers, see [Omarchy Austin Dark](https://github.com/jacob-vincent-mink/omarchy-austin-dark).

# Omarchy Austin Light

A light Omarchy theme inspired by Austin's skyline and Lady Bird Lake. Limestone surfaces, river blue, and park green pair with three daylight wallpapers, including a historical view of West Austin.

Install with `omarchy theme install https://github.com/jacob-vincent-mink/omarchy-austin-light.git`, then run `omarchy theme set austin-light`. Cycle the three wallpapers with `omarchy theme bg next`.

For the night and sunset wallpapers, see [Omarchy Austin Dark](https://github.com/jacob-vincent-mink/omarchy-austin-dark).

The two modern wallpapers are AI-edited versions of the credited photos, then resized to 3840 pixels wide for desktop use. The image edits were rendered at roughly 1500 pixels wide, so the JPEG dimensions do not represent native 4K detail.

The historical wallpaper is a crop of the Library of Congress scan, with its border and caption removed. The original scene is unchanged. The photograph dates from before 1900; the Library of Congress lists no known restrictions on images made by the U.S. government and notes that copied images may have different rights. Wheelock's original photograph is from the 19th century.
